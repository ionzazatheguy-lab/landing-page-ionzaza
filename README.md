# ionzaza — AI & Automation

A high-performance, aesthetically pleasing landing page for **ionzaza**, an AI & automation consultancy. This site is designed to showcase services, social proof, and convert visitors into leads through a streamlined discovery call process.

## 🚀 Overview

ionzaza helps businesses scale through intelligent lead generation, sales automation, and custom AI workflows. This landing page reflects a modern, "tech-forward" aesthetic with smooth animations, high-contrast typography, and a grain-textured UI.

## 🛠️ Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Dynamic Background**: Custom "tech-bg" canvas animation for an immersive feel.
- **Interactive UI**: Scroll-triggered animations, text-wipe reveals, and custom hover states.
- **Grain Overlay**: A subtle SVG noise filter for a premium, textured look.
- **Consultation Funnel**: Integrated lead capture form for booking discovery calls.

## 🏗️ Technical Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **Vanilla CSS**: Custom properties (variables), Flexbox, Grid, and keyframe animations.
- **Vanilla JavaScript**: Lightweight interactions, scroll observation, and form handling.
- **Typography**: Uses *Bricolage Grotesque* and *Instrument Serif* via Google Fonts.

## 💻 Getting Started

This is a static site with no build requirements.

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```
2. **Open the site**:
   Simply open `index.html` in any modern web browser.

Alternatively, serve it using a simple static server:
```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```
